# Named, Ignored, and navigation

[Visual tour](../visual-tour.md) · [User guide](../user-guide.md)

After explicit Sync, named people appear in **Named**. Search by name, edit a
name, or choose an existing person from suggestions to queue a merge. These
edits also go through Pending before they reach Immich.

<a href="../images/visual-tour/named-people.jpg">
  <img src="../images/visual-tour/named-people.jpg" alt="Named view with fictional people and editable name fields" width="840">
</a>

**Ignored** lists people hidden in Immich. Choosing **Restore** queues an
unhide action in Pending; Sync applies it. The screenshot shows fictional
ignored clusters, not people hidden from a real library.

<a href="../images/visual-tour/ignored.jpg">
  <img src="../images/visual-tour/ignored.jpg" alt="Ignored view with fictional clusters and Restore buttons" width="840">
</a>

The left navigation links to each main section, with **Clusters** and
[**Group photos**](group-photos.md) grouped under **Naming**. The mobile
**Menu** opens that navigation as a drawer. **Per page** changes the page size
for lists. Each section
has its own URL, so reload and browser Back or Forward keep your place. The
**Reload** button refreshes people from Immich, while local Pending changes
remain available for review.

Workbench's local SQLite state and browser settings are explained in
[Getting started](../getting-started.md). To start again with a new cluster,
return to [Naming people](naming.md).
