# Synthetic tour portraits

These six JPEG portraits depict fictional, AI-generated people. They were
cropped from the repository's existing synthetic visual-tour screenshots;
no real Immich library or private user data was used.

Original synthetic images: `docs/images/visual-tour/named-people.png`,
`name-suggestions.png`, and `investigate.png`.

The documentation mock composes them into invented photographs and exposes
invented face records. See [Writing guides](../../docs/writing-guides.md).
